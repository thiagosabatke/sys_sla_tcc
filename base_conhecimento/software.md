# Categoria: Software

Problemas com programas, sistemas, aplicativos, licenças e erros de tela.

## Exemplos de chamados típicos
- Sistema trava ou fecha sozinho
- Erro ao abrir um programa
- Preciso de instalação ou atualização de um software
- Solicitação de licença de um programa
- Mensagem de erro desconhecida na tela

## Regras de urgência
- Alta: sistema usado por toda a equipe parado ou com erro crítico
- Média: erro individual que impede uma tarefa específica
- Baixa: solicitação de instalação/atualização sem urgência

## Procedimento padrão
1. Reproduzir o erro e anotar a mensagem exata, se houver
2. Verificar se é um problema conhecido (checar histórico de chamados similares)
3. Encaminhar para a equipe de suporte de sistemas se não houver solução imediata
