# Sistemas, programas e licenças

Problemas com programas, sistemas, aplicativos, licenças e erros de tela.

## Exemplos de chamados típicos
- Sistema trava ou fecha sozinho
- Erro ao abrir um programa
- Preciso de instalação ou atualização de um software
- Solicitação de licença de um programa
- Mensagem de erro desconhecida na tela

## Regras de urgência
- Alta: sistema usado por toda a equipe parado ou com erro crítico
- Média: erro individual que impede uma tarefa específica
- Baixa: solicitação de instalação/atualização sem urgência

## Procedimento padrão
1. Reproduzir o erro e anotar a mensagem exata, se houver
2. Verificar se é um problema conhecido (checar histórico de chamados similares)
3. Encaminhar para a equipe de suporte de sistemas se não houver solução imediata

## Informações que devem constar no chamado
- Nome do sistema, programa ou versão utilizada
- Tela, funcionalidade ou etapa em que o erro acontece
- Mensagem de erro completa e horário da ocorrência
- Usuários, setor e operação afetados
- Passos para reproduzir o problema e alteração recente percebida

## Boas práticas de diagnóstico
- Fechar e abrir novamente o programa antes de registrar a ocorrência.
- Evitar reinstalar, apagar arquivos ou limpar dados sem autorização do suporte.
- Anexar captura de tela sem expor senhas, tokens, dados pessoais ou dados financeiros.
- Informar se o erro ocorre em outro computador ou com outro usuário.

## Instalação, atualização e licença
- Informar o software solicitado, finalidade de uso e equipamento/usuário destinatário.
- Para licença, informar se é uma nova necessidade ou substituição de licença existente.
- Instalações sem urgência devem ser classificadas como baixa prioridade.

## Criticidade sugerida
- Crítica: sistema corporativo essencial indisponível para toda a empresa.
- Alta: sistema essencial indisponível para um setor ou processo com prazo imediato.
- Média: erro individual que bloqueia uma tarefa importante.
- Baixa: melhoria, atualização planejada ou solicitação de novo software.

## Casos recorrentes
| Situação | Dados que ajudam o atendimento |
| --- | --- |
| Programa fecha sozinho | nome, versão, ação que provoca a falha e mensagem |
| Erro de acesso ao sistema | usuário, tela, código do erro e horário |
| Relatório não gera | filtro utilizado, período e formato desejado |
| Sistema lento | tela/funcionalidade, horário e usuários afetados |
| Instalação de programa | nome, finalidade, equipamento e aprovação necessária |

## Perguntas para a coleta da IA
- Qual é o nome do sistema e em qual tela o problema acontece?
- Qual ação você realiza imediatamente antes de aparecer o erro?
- Você consegue reproduzir a falha sempre ou ela ocorre de forma intermitente?
- Outros usuários conseguem executar a mesma tarefa?
